# OOSD C++ UML Practice

A structured learning repository for Object Oriented System Design, UML, and C++.

## Learning Goals

- C++ from fundamentals to advanced
- Object-Oriented Programming
- UML modeling
- Object-Oriented Analysis and Design
- Design and implementation
- Interview preparation
- Real-world projects

## Repository Structure

- `01_UML` — UML and system modeling
- `02_CPP` — C++ fundamentals, OOP and advanced C++
- `03_OOSD_Analysis_Design` — OO analysis and design
- `04_Design_Practice` — design exercises
- `05_Interview_Preparation` — interview-level problems
- `06_Mini_Projects` — small practical projects
- `07_Capstone_Project` — complete OOSD project
